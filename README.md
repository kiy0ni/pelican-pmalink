# Pelican phpMyAdmin SSO Plugin (PmaLink)

This plugin adds an "Open in phpMyAdmin" button directly in the Pelican panel's database management interface. It automatically connects users to their database via Single Sign-On (SSO), skipping the login screen.

## 1. Pelican Installation

1. Download the latest release (`.zip` file).
2. Go to the **Plugins** tab in your Pelican admin panel.
3. Click **Import** and upload the zip file.
4. Once installed, click the **Settings** icon on the PmaLink plugin.
5. Enter your public phpMyAdmin URL (e.g., `https://pma.your-domain.com`) and save.

## 2. phpMyAdmin Server Configuration

Your phpMyAdmin server must be able to validate tokens generated by Pelican.

1. SSH into the server hosting phpMyAdmin.
2. Create a `signon.php` file in the root of your phpMyAdmin directory (e.g., `/usr/share/phpmyadmin/signon.php`).
3. Insert the following PHP code. **Do not forget to replace the Pelican URL on line 6**:

```php
<?php
$token =$_GET['token'] ?? '';
if (!$token) die("Missing token.");

// REPLACE WITH YOUR PELICAN PANEL URL
$panelUrl = "[https://panel.your-domain.com](https://panel.your-domain.com)";
$url = $panelUrl . "/sso-verify.php?token=" . $token;

$ch = curl_init($url);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
$response = curl_exec($ch);
$httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
curl_close($ch);

$data = json_decode($response, true);

if ($httpCode !== 200 \vert{}\vert{} !$data) {
    die("SSO Error: Unable to validate token with Pelican.");
}

session_set_cookie_params(0, '/', '', true, true);
session_name('SignonSession');
session_start();

$_SESSION['PMA_single_signon_user'] =$data['user'];
$_SESSION['PMA_single_signon_password'] =$data['password'];
$_SESSION['PMA_single_signon_host'] =$data['host'];

header('Location: index.php');
exit;
\```

4. In your phpMyAdmin `config.inc.php` file, ensure the authentication mode is set to `signon`:
```php
$cfg['Servers'][$i]['auth_type'] = 'signon';
$cfg['Servers'][$i]['SignonSession'] = 'SignonSession';
$cfg['Servers'][$i]['SignonURL'] = 'signon.php';
\```
